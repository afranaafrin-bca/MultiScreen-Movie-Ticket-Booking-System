# Multi Screen - Movie Ticket Booking System

## About the Project
A Java-based movie ticket booking system developed using Java Swing,
JDBC and MySQL.

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- Maven
- IntelliJ IDEA

## Features
- Movie management
- Theatre management
- Screen management
- Showtime management
- Seat selection
- Classic and Premium seats
- Dynamic ticket pricing
- Booking confirmation
- Movie poster display
- Booking cancellation
- View bookings

## Project Flow
Movie → Theatre → Screen → Showtime → Seat Selection → Booking → Confirmation

## Database
The application uses MySQL to store movies, theatres, screens,
showtimes, seats and booking information.
